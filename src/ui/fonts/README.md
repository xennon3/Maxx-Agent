# Theme fonts

Latin subsets (woff2) from Google Fonts, baked into maxx.exe so the 🖌 Themes work offline.
All are under the SIL Open Font License 1.1 (https://openfontlicense.org): Space Grotesk, Space Mono,
VT323, IBM Plex Mono, IBM Plex Sans Condensed, Orbitron, Exo 2, Architects Daughter, Archivo Black,
Bricolage Grotesque, Syne, Outfit.
